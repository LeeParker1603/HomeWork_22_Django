# Веб-приложение на Django (Развертывание и работа с шаблонами)

Учебный проект, демонстрирующий основы работы с веб-фреймворком Django, архитектурой MVC/MVT, настройкой маршрутизации и интеграцией готовой верстки в шаблоны.

## Используемые технологии
* **Backend:** Python 3, Django 6.x
* **Менеджер зависимостей:** Poetry (конфигурация в `pyproject.toml`)
* **Frontend:** HTML5, CSS3, Bootstrap 5 (локальное подключение статических файлов)

## Структура проекта
* `config/` — главная директория конфигурации Django-проекта (`settings.py`, `urls.py`).
* `catalog/` — Django-приложение для управления каталогом и страницами сайта.
  * `templates/catalog/` — папка с HTML-шаблонами (`home.html`, `contacts.html`).
  * `static/catalog/` — папка с локальной статикой (`bootstrap.min.css`, скрипты и изображения).
* `pyproject.toml` / `poetry.lock` — файлы управления зависимостями проекта.
* `.gitignore` — конфигурация для исключения служебных файлов PyCharm, базы данных (`db.sqlite3`) и окружения.

## Реализованный функционал

1. **Инициализация проекта:** Развернута структура Django-проекта с изолированным окружением Poetry.
2. **Создание приложения:** Зарегистрировано приложение `catalog` в настройках `INSTALLED_APPS`.
3. **Маршрутизация (URLs):** Настроена схема разделения маршрутов. Главный файл `config/urls.py` через `include` подключает адреса из `catalog/urls.py`. Все URL-адреса спроектированы со слэшем на конце согласно правилам Django.
4. **Контроллеры (Views):** 
   * `home_view` — отвечает за отображение главной страницы (`home.html`).
   * `contacts_view` — отвечает за отображение страницы контактов (`contacts.html`).
5. **Обработка данных (POST):** В контроллере контактов реализован перехват `POST`-запроса от формы обратной связи. Данные пользователя (Имя, Email, Сообщение) успешно извлекаются и выводятся в консоль сервера.
6. **Локальная статика:** Подключение стилей и JS-скриптов Bootstrap переведено на тег `{% static %}` для автономной работы приложения без внешних CDN-сетей.

## Как запустить проект

1. Убедитесь, что у вас установлен Poetry.
2. Установите зависимости проекта внутри виртуального окружения:
   ```bash
   poetry install
   ```
3. Примените базовые миграции базы данных:
   ```bash
   poetry run python manage.py migrate
   ```
4. Запустите локальный сервер разработки:
   ```bash
   poetry run python manage.py runserver 127.0.0.1:8000
   ```
5. Откройте браузер по адресам:
   * Главная страница: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
   * Страница контактов: [http://127.0.0.1:8000/contacts/](http://127.0.0.1:8000/contacts/)
