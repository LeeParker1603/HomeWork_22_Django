# Простой веб-сервер на Python (HTTP-протокол)

Учебный проект, демонстрирующий основы работы протокола HTTP, обработку GET/POST запросов и верстку интерфейса панели управления с использованием фреймворка Bootstrap.

## Используемые технологии
* **Backend:** Python 3 (встроенные модули `http.server`, `urllib.parse`)
* **Frontend:** HTML5, CSS3, Bootstrap 5 (подключение стилей через удаленный репозиторий / CDN)

## Структура проекта
* `catalog/` — директория с исходными HTML-страницами макетов.
  * `main_page.html` — Главная страница (прототип сетки Pricing).
  * `catalog.html` — Страница каталога (прототип Album).
  * `category.html` — Страница категории товаров.
  * `contacts.html` — Страница «Контакты» с формой обратной связи.
* `server.py` — Python-скрипт локального веб-сервера.
* `.gitignore` — файл конфигурации для исключения служебных файлов IDE (PyCharm) и окружения (`venv`).

## Реализованный функционал

### Задание 1: Верстка макетов
Собраны прототипы четырех страниц с использованием Bootstrap-стилей и интерактивным боковым меню. Структурно страницы полностью соответствуют выданным макетам.

### Задание 2: Обработка GET-запросов
Реализовано простое веб-приложение. Сервер на **любой** входящий `GET`-запрос считывает файл `contacts.html` с помощью контекстного менеджера `with open()` и возвращает его пользователю с корректным заголовком `Content-type: text/html`.

### Дополнительное задание (*): Обработка POST-запросов
Реализован метод `do_POST` для приема данных из формы обратной связи на странице «Контакты». При отправке формы сервер парсит входящие данные и выводит их в консоль PyCharm в удобном для чтения формате.

## Как запустить проект

1. Убедитесь, что у вас установлен Python 3.
2. Скачайте проект и откройте его в PyCharm.
3. Запустите файл сервера:
   ```bash
   python server.py
   ```
4. Откройте любой браузер и перейдите по адресу:
   ```text
   http://localhost:8000
   ```
5. Для проверки `POST`-запроса заполните форму на странице и нажмите кнопку «Отправить». Данные отобразятся в консоли запущенного сервера.
